`NetVtkModules` names the NetVtk libraries an app uses by their modules (`Common;Filters;Rendering`): the build copies those libraries, NetVtkRuntime and the VTK libraries these load only, on .NET Framework and .NET; Common and Rendering take 56 of the 84 files on win-x64. Each runtime package lists what its natives load, read from the files at pack time, and keeps what `NetVtkRequiredNative` items name, a binding's natives' imports, with all they load.
